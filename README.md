Опис предметної області: це програмна система для автоматизації електронної комерції та роздрібного продажу товарів через мережу Інтернет. Система забезпечує ведення каталогу товарів із поділом на категорії, керування залишками на складі та облік користувачів. Покупці можуть формувати кошик замовлень, обирати спосіб оплати й доставки та відстежувати статус виконання покупки. Адміністратор має змогу додавати нові позиції, оновлювати ціни та обробляти вхідні замовлення.
